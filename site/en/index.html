Network backups, changes and compliance, on your own server.

OpenNCCM backs up, versions, compares and audits switches, routers and firewalls from about 70 vendors. It detects changes in real time and rolls back when something goes wrong. Free, open source, in English and Spanish.

Features

Everything you expect from an NCCM, without licenses

What commercial network configuration management tools offer, on a server you own and with your data in-house.

Back up and compare

  • Manual, scheduled and change-triggered backups (syslog), encrypted with AES-256.
  • Versions, baseline and side-by-side diff, between versions or between devices.
  • Recovery backups and restore on a new server.

Change with control

  • Configlets with Jinja2 templates for changes on many devices.
  • Change requests with approval and safe rollback for each platform.
  • SSH console in the browser, with read-only mode, recordings and an optional AI assistant.

💾

Backups

Manual, scheduled and automatic when a change is detected through syslog; “Back up all” shows its progress and retries only the failed ones. Running and startup configs, encrypted with AES-256. On MikroTik, download the .rsc and the .backup; on WatchGuard, the XML configuration and the full encrypted image (.fxi).

🔍

Versions and diff

Version timeline, tags, baselines and a reference configuration per model and search for text or an IP inside each version. Every backup keeps the firmware the device had and flags when it changed. Side-by-side or unified comparison, between versions or between devices. Every version copied to GitHub, GitLab or Gitea, with passwords masked.

🛠️

Controlled changes

Configlets with Jinja2 templates for bulk changes (ten included each for MikroTik, Extreme EXOS and VOSS, EdgeSwitch, WatchGuard and ArubaOS), change requests with approval, and safe per-platform rollback (MikroTik safe mode, Junos commit confirmed). Changes that would lock OpenNCCM out of a device cannot be approved, and before rebooting devices or shutting ports it shows what loses service.

🛡️

Compliance

Device × policy map, per-rule remediation and an editor that tests every rule live. Packs for PCI DSS 4.0, HIPAA, SOX and Cisco IOS, Junos, Extreme VOSS, Ubiquiti, MikroTik, FortiGate, WatchGuard, ArubaOS and Ubuntu/Debian hardening.

📦

Firmware

Know which newer firmware exists for each device and how many vulnerabilities it fixes. Verified download (SHA-256) and remote upgrades for MikroTik (.npk or online) and Ubiquiti (airMAX, airFiber and EdgeRouter), with a check that the device ended up on the new version, and end of life on one page.

🚨

Vulnerabilities

Firmware CVEs for every device (NVD, 70 device types, also by model), grouped by vulnerability and flagged “actively exploited” from the CISA KEV catalog.

🖥️

Web console

SSH from the browser with colors, autocomplete and a read-only mode. Several sessions at once, the same query across many devices, 758 recipes for every device with a command line (with a “Verified” badge on those tested), favorite commands, recordings and role-based access. Optional AI assistant with your own provider: a chat across the whole system that queries read-only and asks for confirmation before acting.

⏰

Day-to-day operations

Device import from Zabbix by group, damaged or replaced devices retired with all their history (and the replacement added in the same step), an API with personal tokens, scheduled tasks without writing cron, alarms by severity, and alerts by email, Teams, Slack or Telegram. A team knowledge base: every closed critical alarm is documented with its cause, steps and check.

📈

Map, inventory and reports

Network map built from LLDP/CDP links (and MikroTik devices through RoMON), 10 layouts, nodes by place and new or lost neighbor alerts; MAC or IP search down to the switch and port; a front view of each device with the status of its ports, power supplies and fans, IP and VLAN inventory with duplicate warnings, activity by source, a day × hour heat map, trends and compliance by policy; on-screen reports, CSV and scheduled email delivery, unused ports and the network document in PDF or Word.

🔐

Access and security

Sign-in with Active Directory and Microsoft Entra ID (Azure AD), with roles from groups. Admin, operator and viewer roles as templates, with per-user permissions (for example, an operator who does not send configurations), a master administrator who cannot be deleted or locked, device groups, two-factor authentication (TOTP), “Remember me on this device” and a complete audit trail.

🎨

Polished interface

“Signal” design with a sidebar and Ctrl K search, in English and Spanish, and each device with its brand logo (73 brands). Fast with thousands of devices: with 2000, the dashboard loads in 0.4 s and the list travels compressed (200 KB instead of 4 MB). Light, dark and high-contrast themes with 7 accent colors; mobile-friendly and accessible (WCAG AA).

♻️

Recovery

Encrypted database backups, SFTP offload, restore onto a new server with its key (SQLite or PostgreSQL), and upgrades that roll back on failure. A device backup can be restored onto another unit of the same model, over SSH or a console cable.

Installation

Up and running in minutes

On a fresh Ubuntu Server 22.04 or 24.04, a single command launches a menu-driven wizard that does everything.

  1. Prepare an Ubuntu Server

    22.04 or 24.04 LTS, physical or virtual. 2 vCPUs and 4 GB of RAM handle up to 300 devices.

  2. Run the installer

    It checks the server, updates Ubuntu and installs anything missing. It asks for the address, time zone, HTTPS type, database, firewall and administrator password.

  3. Open the web interface

    When it finishes it shows the address and credentials. Install the authority from https://SERVER/certificado on your PC and the browser stops showing warnings.

  4. Upgrade with one click

    With Update now in the new-version notice, or from System → Update. It takes a backup first and, if the new version does not respond, it rolls back on its own.

Install 
$ curl -fsSL https://raw.githubusercontent.com/Gaaraalex/opennccm/main/install.sh -o install.sh && sudo bash install.sh
Upgrade from the console 
$ sudo opennccm update
Unattended installation (no questions)
For automation 
$ curl -fsSL https://raw.githubusercontent.com/Gaaraalex/opennccm/main/install.sh | \
  sudo bash -s -- --unattended --host 10.0.0.5 --admin-pass 'UnaClaveSegura123'

All options with sudo bash install.sh --help: HTTPS with Let's Encrypt or a self-signed certificate, PostgreSQL, firewall, email, a specific version…

Every change is tested automatically on Ubuntu 22.04 and 24.04: installation, wizard, upgrade, rollback and recovery from a broken release.

Server commands

The opennccm tool is installed with the application. Commands that change the server (upgrade, roll back, backups, removing two-factor) use sudo because they need administrator rights; read-only ones do not.

opennccm statusStatus, version and updates
sudo opennccm updateUpgrade (or --check)
sudo opennccm rollbackGo back to the previous version
sudo opennccm backupRecovery backup
sudo opennccm reset-2fa USERRemove two-factor
sudo opennccm set-master USERRecover the master administrator
opennccm logs -fService log
