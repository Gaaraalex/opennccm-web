Network backups, changes and compliance, on your own server.

OpenNCCM backs up, versions, compares and audits switches, routers and firewalls from about 70 vendors. It detects changes in real time and rolls back when something goes wrong. Free, open source, in English and Spanish.

Features

Everything you expect from an NCCM, without licenses

What commercial network configuration management tools offer, on a server you own and with your data in-house.

💾

Backups

Manual, scheduled and automatic when a change is detected through syslog. Running and startup configs, encrypted with AES-256.

🔍

Versions and diff

Version timeline, tags and baselines. Side-by-side or unified comparison, between versions or between devices.

🛠️

Controlled changes

Configlets with Jinja2 templates for bulk changes, change requests with approval, and manual or automatic rollback.

🛡️

Compliance

Device × policy map, per-rule remediation and an editor that tests every rule live. Packs for PCI DSS 4.0, HIPAA, SOX and Cisco IOS / Junos hardening.

📦

Firmware

Image repository, remote upgrades (SCP, MD5, boot and reload) and end of life / end of support on one page, with each device's remaining support.

🚨

Vulnerabilities

Firmware CVEs for every device (NVD), grouped by vulnerability and flagged “actively exploited” from the CISA KEV catalog.

🖥️

Web console

SSH to the device from the browser, in a dialog with reconnect and full screen or in its own window, with optional automatic login and full auditing.

⏰

Day-to-day operations

Scheduled tasks without writing cron, alarms by severity, and alerts by email, Teams, Slack or Telegram.

📈

Analytics and reports

Activity by source, a day × hour heat map, trends and compliance by policy; on-screen reports, CSV and scheduled email delivery.

🔐

Access and security

Sign-in with Active Directory and Microsoft Entra ID (Azure AD), with roles from groups. Admin, operator and viewer roles, device groups, two-factor authentication (TOTP) and a complete audit trail.

🎨

Polished interface

“Signal” design with a sidebar and Ctrl K search, in English and Spanish. Light, dark and high-contrast themes with 7 accent colors; mobile-friendly and accessible (WCAG AA).

♻️

Recovery

Encrypted database backups, SFTP offload, restore, and upgrades that roll back on failure.

Installation

Up and running in minutes

On a fresh Ubuntu Server 22.04 or 24.04, a single command launches a menu-driven wizard that does everything.

  1. Prepare an Ubuntu Server

    22.04 or 24.04 LTS, physical or virtual. 2 vCPUs and 4 GB of RAM handle up to 300 devices.

  2. Run the installer

    It checks the server, updates Ubuntu and installs anything missing. It asks for the address, time zone, HTTPS type, database, firewall and administrator password.

  3. Open the web interface

    When it finishes it shows the address and credentials. Install the authority from https://SERVER/certificado on your PC and the browser stops showing warnings.

  4. Upgrade with one click

    From System → Update. It takes a backup first and, if the new version does not respond, it rolls back on its own.

Install 
$ curl -fsSL https://raw.githubusercontent.com/Gaaraalex/opennccm/main/install.sh -o install.sh && sudo bash install.sh
Upgrade from the console 
$ sudo opennccm update
Unattended installation (no questions)
For automation 
$ curl -fsSL https://raw.githubusercontent.com/Gaaraalex/opennccm/main/install.sh | \
  sudo bash -s -- --unattended --host 10.0.0.5 --admin-pass 'UnaClaveSegura123'

All options with sudo bash install.sh --help: HTTPS with Let's Encrypt or a self-signed certificate, PostgreSQL, firewall, email, a specific version…

Every change is tested automatically on Ubuntu 22.04 and 24.04: installation, wizard, upgrade, rollback and recovery from a broken release.

Requirements

Ports: TCP 443 (web) and UDP 514 (syslog from devices); outbound TCP 22 to the devices.
